# How to put this portfolio on GitHub (about 10 minutes)

## 1. Edit three things first
Open `index.html` in any text editor (Notepad works) and search for:
- `your.email@example.com` → replace with your real email
- `https://www.linkedin.com/in/your-profile` → replace with your LinkedIn link, or delete that button
- Check the facts. In particular, check the foundation numbers in Project 03, which I read from a small image of your board.

In `README.md` and `PROFILE-README.md`, replace `YOUR-USERNAME` with your GitHub username.

## 2. Publish the website
1. Sign in at github.com and click **+ → New repository**.
2. Name it exactly **`YOUR-USERNAME.github.io`**, make it **Public**, then click **Create repository**.
3. Click **uploading an existing file**. Drag in everything from this folder **except** `PROFILE-README.md` and this guide. Make sure the `assets` folder is included.
4. Click **Commit changes**.
5. Go to **Settings → Pages**. Under "Branch", choose **main** and **/ (root)**, then click **Save**.
6. After 1–2 minutes, your site is live at `https://YOUR-USERNAME.github.io`.

## 3. Add the profile README (optional but recommended)
1. Create another new public repository named **exactly your username** (e.g. `tawseefmasud`).
2. Tick **Add a README file** and create it.
3. Edit that README, paste in the contents of `PROFILE-README.md`, and commit.
   It now shows at the top of your GitHub profile and links to the portfolio.

## 4. Adding more projects later
Copy a whole `<section class="project">…</section>` block in `index.html`, change the text and image paths, and put the new images in `assets/img/`.
